mao-method · 毛选分析使用指南
用《毛泽东选集》的辩证唯物主义方法论，处理三类反复出现的复杂问题
一 · 三种模式（自动判定 / 可点名）
A 决策诊断
看不清局势、抓不住重点
核心：实事求是 + 抓主要矛盾 + 两点论/重点论
例：“好几件事同时在，不知道先做哪个”
B 战略推进
长期目标推不动、方向反复变
核心：战略藐视/战术重视 + 集中力量 + 实践—认识循环
例：“做了很久没起色，要不要换方向”
C 说服沟通
动员、谈判、说服他人
核心：群众路线 + 调查研究 + 理论联系实际
例：“道理讲了很多，对方就是不听”
二 · 分析工作流
① 触发
直接描述处境
→
② 判模式
A / B / C
→
③ 实事求是
还原事实
→
④ 抓主要矛盾
定核心点
→
⑤ 矛盾两面
有利/不利
→
⑥ 策略
具体分析
→
⑦ 下一步
第一个动作
→
⑧ 处方
一句话结论
三 · 可视化
有结构（比较/流程/维度）时自动配图；一句话结论只给文字。
深色高亮 = 主要矛盾；箭头 = 执行顺序；标“示意”为简化。
说“画个图”强制要图；“只要文字”关闭配图。
四 · 边界
只做方法论，不评论政治立场、不评价历史人物功过。
事实不足标注“基于不完整信息”，不硬给结论。
投资/法律/健康等重大决策提醒咨询专业人士。
