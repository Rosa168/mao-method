# mao-method

用《毛泽东选集》的辩证唯物主义方法论诊断复杂问题，按场景提供决策诊断、战略推进、说服沟通三种模式。当用户看不清局势、抓不住重点、决策反复犹豫、长期目标推不动，或需要动员说服他人时使用。

## 安装

```bash
npx -y skills add Rosa168/mao-method -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $mao-method，用《毛泽东选集》方法论诊断当前问题并给出可执行的下一步。

## 运行依赖

- 支持 Agent Skills 的客户端
