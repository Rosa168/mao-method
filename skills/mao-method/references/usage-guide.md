# mao-method 使用指南

> 本指南说明 `mao-method` 解决什么问题、怎么用、出什么图、有哪些边界。第一次触发本 skill 时，助手会先向用户展示本指南。

---

## 1. 这个 skill 解决什么问题

用《毛泽东选集》的辩证唯物主义方法论，处理三类**反复出现的复杂问题**：

| 模式 | 解决的问题 | 典型一句话 |
|---|---|---|
| **A 决策诊断** | 看不清局势、抓不住重点、不知道该先干什么 | "好几件事同时在，不知道先做哪个" |
| **B 战略推进** | 长期目标反复推不动、方向反复变 | "做了很久没起色，要不要换方向" |
| **C 说服沟通** | 需要动员、谈判、说服、影响他人 | "道理讲了很多，对方就是不听" |

它**不解决**：一句话的事实问答、无需抓重点的简单咨询、纯数据查询、政治立场或历史评价。

## 2. 怎么用

**方式一（推荐）**：直接说你的处境或问题。助手会自动判定属于 A / B / C 哪种模式，按对应流程分析。

**方式二（点名模式）**：显式指定，例如——
- "用毛选方法帮我做决策"
- "用毛选方法帮我分析这个长期目标"
- "用毛选方法帮我说服某个人"

每次分析都会输出一份**结构化报告**：

```
事实还原（实事求是） → 主要矛盾（抓主要矛盾）
→ 矛盾的两个方面（两点论） → 策略（具体问题具体分析）
→ 具体下一步（第一个动作） → 一句话处方
```

## 3. 三种模式的核心方法

| 模式 | 核心方法（对应毛选方法论） |
|---|---|
| A 决策诊断 | 实事求是 + 抓主要矛盾 + 两点论 / 重点论 |
| B 战略推进 | 战略上藐视 / 战术上重视 + 集中力量打歼灭战 + 实践—认识循环 |
| C 说服沟通 | 群众路线 + 调查研究 + 理论联系实际（讲利益不只讲道理） |

## 4. 可视化：会出什么图、怎么读

- **什么时候出图**：有比较、流程、机制、架构、维度等结构关系时自动配图；一句话结论 / 简单确认只给文字。
- **毛选分析出的图**：模式 A 出"主要矛盾判断框架图"（双栏维度 + 主次）；模式 B 出"阶段 / 复盘流程示意"；模式 C 出"群众路线流程 / 关系图"。
- **怎么读图**：深色高亮 = 主要矛盾或主路径，先看它；箭头 / 横向流程 = 执行顺序；标了"示意"的是简化示意，不代表精确数据或官方结构。
- **怎么触发**：默认自动。说"画个图 / 做个流程示意"强制要图；说"只要文字"关闭配图。
- **数据来源**：图里的内容只来自你提供的真实信息；示例数据会明确标"示意 / 示例"，不编造。

## 5. 边界与停止条件

- 只做方法论分析，不评论政治立场、不评价历史人物功过、不介入政治性争议。
- 事实不足且追问无法补齐时，会标注"此结论基于不完整信息"，不硬给结论。
- 涉及重大决策（投资、法律、健康、人身）时，会提醒咨询相应专业人士。
- 说服模式遇到诱导、欺骗、操纵时立即停止——说服是讲清利益与事实，不是操控。

## 6. 常见问题（FAQ）

**Q：图能导出吗？**
分析配图会以 HTML 文件交付到项目目录，可直接浏览器打开、另存或分享。

**Q：能改图吗？**
能。说"把主要矛盾换个颜色 / 改成左右结构"，按新要求重画。

**Q：我只想要结论，不要分析过程？**
可以，说"直接给结论和下一步"，会精简为结论 + 处方。
